# Changelog

All notable changes to Notificator for Astro will be documented in this file.

## 0.1.1 - 2026-09-01

- Update the package homepage to the Notificator getting-started guide.

## 0.1.0 - 2026-08-31

- Add a typed, server-only wrapper around the official Notificator Node.js SDK.
- Add helpers for Astro Actions, API routes, middleware, and server-rendered code.
- Add an optional successful-build notification integration.
- Add environment-based API-key configuration with no client-side credential injection.
- Add tests, examples, package checks, and initial security guidance.
